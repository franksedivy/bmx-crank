# Additional cloud variants

Generated with the built-in image generator, using `far-source.png` as the
style reference. Sources: `cloud-d-source.png`, `cloud-e-source.png`,
`cloud-f-source.png`. `export-cloud.swift` trims and converts each into a
monochrome PNG under `Source/images/clouds/`, with two transparent pixels of
padding and a maximum canvas of 110 × 40 pixels.

## Cloud d

Use case: stylized-concept. Create ONE isolated cloud sprite for a monochrome Playdate BMX game: a long, very low wispy cloud with a gently scalloped upper edge and tapered ends. Reference image is ONLY the black-and-white ink style reference; do not reproduce its three-cloud layout. Single cloud centered with transparent margins, around 3:1 width to height, clear readable silhouette for a final approximately 90-110 pixel wide sprite. Opaque white cloud body, crisp thin black contour, a few black diagonal shadow marks under the base and sparse black stipple. Match the existing hand-inked game art. Pure black and white plus transparent empty background. No grey blur, gradients, scenery, other clouds, sun, birds, text, watermark, or shadow outside the cloud.
